# Security policy

Please do not report vulnerabilities in public issues. Contact the repository owner through the private vulnerability reporting feature on GitHub. Include a concise impact description and reproduction steps, with secrets and private data removed. Acknowledgment and remediation timelines are not guaranteed while this project is new and maintained by one person.

Never send secrets or private repository content to an AI provider. The built-in redaction is best-effort. Review every generated finding and suggestion; this tool does not perform a security audit.
